## Ana Gabriela Argüello Cedeño and Laura Isabel Olivero Alvarez 

Using openMusic, we created a melody for the Sonic the Hedgehog game.

In the tool, we used different functions such as omploops, repeatN, and concatenations to create a looping effect. For the notes, we used chords, in which we entered the number of each required note. These chords were then combined into what would become chord sequences.
